# Выполнение планов

## Обзор

Загрузи план, критически проверь, выполни все задачи, доложи о завершении.

**Объяви в начале:** «Использую скилл executing-plans для выполнения плана.»

## Процесс

### Шаг 1: Загрузить и проверить план
1. Прочитать файл плана
2. Критически проверить — выявить вопросы или опасения по поводу плана
3. Если есть опасения: обсудить с пользователем до начала
4. Если нет — создать задачи и приступить

### Шаг 2: Выполнить задачи

Для каждой задачи:
1. Отметить как in_progress
2. Следовать каждому шагу точно (план содержит мелкие шаги)
3. Запускать верификации согласно плану
4. Отметить как completed

### Шаг 3: Верифицировать и доложить

После завершения всех задач:
1. Запустить все верификации из плана ещё раз
2. Убедиться что все проверки прошли
3. **ОБЯЗАТЕЛЬНО:** Вызвать скилл verification-before-completion перед любым заявлением о завершении
4. Доложить о завершении: что реализовано, что протестировано, были ли отклонения от плана

## Когда остановиться и попросить помощи

**НЕМЕДЛЕННО ОСТАНОВИТЬСЯ когда:**
- Блокер (отсутствующая зависимость, верификация не проходит, инструкция непонятна)
- В плане критические пробелы, не позволяющие начать
- Непонятна инструкция
- Верификация раз за разом не проходит

**Спрашивай, а не угадывай.**

## Когда вернуться к предыдущим шагам

**Вернуться к Проверке (Шаг 1) когда:**
- Пользователь обновил план по результатам обсуждения
- Нужно переосмыслить фундаментальный подход

**Не продавливай блокеры** — останавливайся и спрашивай.

## Помни
- Сначала критически проверяй план
- Следуй шагам плана точно
- Не пропускай верификации
- Вызывай скиллы когда план на это указывает
- При блокере — останавливайся, не угадывай

## Интеграция

**Работает совместно с:**
- **writing-plans** — создаёт план, который этот скилл выполняет
- **unit-test-writer** — если план указывает написать тесты
