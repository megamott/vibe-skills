# Пример: сбор доказательств по слоям

Для сбора доказательств в многокомпонентной системе — фиксируй что входит и выходит на каждой границе компонентов.

Подставь команды своего стека (из `CLAUDE.md`, раздел «Тестирование» / «Настройка разработки»). Примеры для разных стеков:

```bash
# Python: запустить конкретный упавший тест
. .venv/bin/activate && pytest tests/path/to/test.py::test_name -v -s

# Node.js
npm test -- tests/path/to/test.spec.js

# Go
go test -run TestName ./path/to/package -v

# Произвольная команда тестов проекта
<команда из CLAUDE.md>
```

Дальше — для каждого следующего слоя добавляй проверки выходов компонента: логи, состояние БД, ответ сервиса, содержимое очереди и т.д.
